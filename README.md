# 方块小世界

一个零依赖、全屏 Canvas 方块沙盒小游戏。打开页面即可游玩，无需安装构建工具或加载外部资源。

## 运行

直接用浏览器打开 [`index.html`](./index.html) 即可运行。也可以在仓库目录启动任意静态文件服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 操作

- `WASD` / 方向键：移动
- `空格`：跳跃
- `Shift`：蹲下
- `Ctrl`：奔跑
- 鼠标左键：破坏目标方块
- 鼠标右键：放置方块或互动
- 鼠标滚轮：调整视野范围
- `1` - `8`：切换物品栏槽位
- `B`：打开或关闭背包
- 点击右上角重置按钮：生成新的随机世界

物品栏初始为空。打开背包后，点击 32 种方块或物品即可把它们加入底部物品栏。操作距离限制为 5.5 格。

## 功能

- 随机生成的地形、树木和初始时间
- 基础横向移动、跳跃、蹲下和奔跑
- 方块放置、破坏与工作台互动提示
- 32 种方块 / 物品
- 自动移动的云层
- 昼夜更替和环境亮度变化
- 全屏响应式布局与移动端适配
- 零依赖原生 HTML、CSS 和 JavaScript

## 项目结构

- `index.html`：游戏界面与 HUD
- `styles.css`：全屏布局、操作提示、物品栏和背包样式
- `game.js`：世界生成、物理、渲染、交互和输入
